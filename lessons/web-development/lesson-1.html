This lesson teaches you what actually happens when you visit a website, then gets your first page on screen. By the end you will explain the roles of browsers, servers, and addresses; create an HTML file; view it in your browser; and understand the basic anatomy of an HTML document. Every website you will ever build rests on this foundation, so make sure each step below works on your machine before moving on.

Here is the web in one paragraph. A website is a collection of files — mostly HTML, CSS, and JavaScript — stored on a computer called a server that is always connected to the internet. When you type an address into your browser, the browser asks the server for the files, downloads them, and renders them into the page you see. HTML describes the content and structure (headings, paragraphs, images). CSS describes the appearance (colors, layout, fonts). JavaScript describes the behavior (things that move, respond, and update). The browser is the program that reads all three and builds the page. When you are learning, your own computer plays both roles: your files sit in a folder, and your browser opens them directly — no server needed until Lesson 8.

You need two tools, both free. A web browser — any current one works — for viewing your pages. And a text editor for writing code: a plain-text editor that does not add formatting. Many systems include one, and there are excellent free code editors available; pick one, install it, and learn two skills in it: creating a new file and saving with the exact name you choose, including the extension. That extension matters: .html tells the browser "this is a web page".

Create a folder called my-site on your computer. Inside it, create a file called index.html (not index.txt — if your system hides extensions, turn that setting on so you can verify). Type the following exactly:

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="utf-8">
<title>My First Page</title>
</head>
<body>
<h1>Hello, web!</h1>
<p>This is my first web page. I built it myself.</p>
</body>
</html>

Now open it: in your file manager, double-click index.html, or drag it into your browser window. You should see a large heading "Hello, web!" and a paragraph beneath it. Congratulations — you are a web developer. Here is what each part does. <!DOCTYPE html> tells the browser this is a modern HTML document. The <html> element wraps everything; lang="en" declares the language. The <head> holds information about the page that is not displayed: <meta charset="utf-8"> sets the character encoding (so special characters display correctly), and <title> sets the text shown in the browser tab. The <body> holds everything visible: <h1> is the top-level heading, <p> is a paragraph. Notice the pattern: an opening tag <p>, content, and a closing tag </p> with a slash. Almost everything in HTML follows this sandwich pattern.

Two beginner mistakes cause most Lesson 1 frustration. First, the file saved as index.html.txt because extensions were hidden — the browser then shows your raw code as text instead of rendering a page. Verify the real filename, rename if needed, and reopen. Second, editing the file but seeing no change in the browser: you must save the file in your editor and then refresh the browser tab. Browsers show the saved version, not your unsaved edits — save, then refresh, every time.

Practice: In your my-site folder, create a second page called about.html with its own <title>, an <h1> with your name, and two paragraphs: one about why you are learning web development, one listing three things you want to build. Open it in your browser and confirm it renders. Then go back to index.html, change the heading text, save, refresh, and confirm the change appears. Finally, open your browser's developer tools (usually F12 or right-click and choose "Inspect") and find your heading in the page structure — you are looking at the same document you wrote, as the browser sees it.
