This lesson gets Python running on your computer and teaches you to run your first program. By the end you will know how to check whether Python is already installed, how to install it if it is not, how to experiment in the interactive prompt, and how to save and run a script file. You will also write your first real code: the print() function for showing output, and variables for storing values. Run every example yourself as you read.

First, check whether Python is already installed. Open a terminal and type python3 --version, then press Enter. If you see something like "Python 3.12.1", you are ready. On some Windows setups the command is python --version instead — try that if the first one is not recognized. If neither works, download the installer for your system from python.org and run it. One important detail on Windows: during installation, check the box labeled "Add python.exe to PATH" before clicking Install. That box lets your terminal find Python, and skipping it is the most common reason beginners cannot run the python command afterward.

With Python installed, open the interactive prompt by typing python3 (or python on Windows) with no file name and pressing Enter. You will see a >>> prompt. You type one line, Python runs it immediately and shows the result. Try typing print("Hello, world!") and pressing Enter — Python prints Hello, world! back at you. Try 2 + 3 and you will see 5. Use the prompt as a scratchpad for the whole course: whenever you wonder what a piece of code does, test it here in seconds instead of guessing. To leave the prompt, type exit() and press Enter.

The prompt is great for experiments, but real programs live in script files. Open a plain text editor and type the following two lines, then save the file as hello.py (make sure it ends in .py, not .txt):

print("Hello, world!")
print("Welcome to Python.")

Now, in your terminal, move to the folder where you saved the file and run python3 hello.py (or python hello.py on Windows). Both lines print. A script is a saved list of instructions Python runs top to bottom — rerunnable, shareable, and easy to build on. Any plain-text editor works; the free VS Code is a popular choice, and Notepad or TextEdit (in plain text mode) are fine for this course.

The print() function displays values on the screen. The parentheses hold what you want to show, and text must be wrapped in quotes so Python knows it is words, not code: print("Good morning") works, while print(Good morning) is an error because Python looks for something named Good. Separate multiple items with commas — print("My name is", name) prints both with a space between them. Numbers need no quotes: print(42) works fine.

Variables store values under names so you can reuse them. You create one with the = sign, which in programming means "store the value on the right into the name on the left": name = "Maya" stores the text Maya in name, and age = 30 stores the number 30 in age. After that, print(name) shows Maya. Names can contain letters, digits, and underscores, but cannot start with a digit and cannot contain spaces — user_name is fine, 1st_place is not. Python is case-sensitive, so Age and age are two different variables. You can change a variable later with a new assignment, like age = 31, and the old value is replaced. Build the habit now: clear names like total_price beat x when you reread code next week.

Two beginner mistakes cause most Lesson 1 frustration. First, mixing up the two places you type code: the >>> prompt belongs only in the interactive prompt, so never type it into a script file, and do not include it when running a file from the terminal. Second, small typing slips: Print("hi") fails because Python's function is lowercase print, and print("hi') fails because the opening double quote must be closed with a double quote, not a single one. When something fails, read the error's last line first, fix one thing, and run again.

Practice: Create a file called about_me.py. In it, store your name in a variable called name, your age in a variable called age, and your favorite hobby in a variable called hobby. Then use print() to display three lines, for example "My name is ..." using the variables rather than typing the values directly into the print calls. Run the file from your terminal. Then, in the interactive prompt, try print(name) before defining it and read the error; then define name = "Test" and print it again. Reading errors calmly is a skill you will use in every lesson.
