This lesson teaches you variables: named boxes that store values your program can use and change. By the end you will know the main Java types for whole numbers, decimal numbers, text, single characters, and true-or-false values; you will declare variables, assign values, combine them with operators, and print results. You will also learn how Java's strict typing protects you and where it catches beginners out. Variables appear in every program you will ever write, so make sure each example below runs on your machine before moving on.

A variable has a type, a name, and a value. The type says what kind of value it can hold, the name is how you refer to it, and the value is what it currently holds. You declare a variable by writing its type, then its name, then an equals sign and a value, ending with a semicolon:

int age = 30;
double price = 12.50;
String name = "Maya";
char grade = 'A';
boolean isOpen = true;

The int type holds whole numbers like 30, -3, and 1000. The double type holds numbers with a decimal point like 12.50 and 98.6. The String type, with a capital S, holds text in double quotes. The char type holds a single character in single quotes, like 'A' or '7'. The boolean type holds only true or false, written in lowercase. You can also declare first and assign later: int score; on one line, then score = 85; on a later line. But you must assign a value before you use a variable, or the compiler will stop you with an error saying the variable might not have been initialized. That is Java protecting you from using a value that was never set.

Java is statically typed, which means each variable keeps its type forever. Once you declare int age, age can only hold whole numbers. Trying to store text in it, like age = "thirty";, is a compile error, not a surprise at runtime. This strictness feels fussy at first, but it catches a whole category of mistakes before your program ever runs. There are two related types worth knowing now: long for very large whole numbers, and float for decimal numbers that use less memory, though double is the usual choice for decimals in beginner code. Type names matter in exact spelling and case: Int and int are different, and only lowercase int is a type. String is the one type name that starts with a capital letter, because it is a class, a fact Lesson 7 will explain.

Operators combine values into new values. Arithmetic operators work like a calculator: + adds, - subtracts, * multiplies, and / divides. Two are special: % gives the remainder after division, so 7 % 2 is 1, and that remainder operator is surprisingly useful for checking even and odd numbers or cycling through positions. Integer division is a classic trap: 7 / 2 in Java is 3, not 3.5, because dividing two ints gives an int and drops the fractional part. If you want 3.5, at least one side must be a double: 7.0 / 2 gives 3.5. The + operator on Strings joins them together: "Good " + "morning" gives "Good morning". You can also join text and numbers: "Age: " + age gives "Age: 30" because Java converts the number to text for the joining. You can change a variable with shorthand: age = age + 1; can be written age++; to add one, and total += 5; adds five to total. These shortcuts are common in real code, so learn to read them even if you write the long form at first.

Two mistakes dominate this lesson. First, using = when you mean ==. A single equals sign stores a value, while a double equals sign compares two values and gives true or false. In Lesson 3 you will write if (age == 18), and writing if (age = 18) instead is an error in Java. Read = as gets, as in age gets 30, and == as equals, and your brain will flag the mix-up. Second, mixing types without converting: String count = "5"; followed by count + 1 does not give 6, it gives the text "51", because + on text joins instead of adding. To turn text into a number you convert explicitly, for example int count = Integer.parseInt("5");. The reverse, turning a number into text, happens automatically when you join it with a String using +, as shown above.

Practice: Write a program called Shop.java that declares variables for an item name (a String), its price (a double), and how many you are buying (an int). Compute the total cost in a new double variable, then print a sentence like "3 notebooks cost 15.0" using the variables, not typed-in numbers. Then add a second program section, or a second small program, that prints the results of 7 / 2, 7.0 / 2, 7 % 2, and 10 % 3, and write a one-line comment in your own words above each print explaining the result. A comment in Java starts with // and runs to the end of the line. Test your program with different prices and quantities and confirm the total changes correctly.
