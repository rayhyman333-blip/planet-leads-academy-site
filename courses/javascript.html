What You Will Learn

  • You will learn how to run JavaScript in your browser's console and inside web pages with script tags, and how to store values with let and const
  • You will learn the core types — strings, numbers, booleans, null, and undefined — plus operators and the strict equality checks that prevent classic bugs
  • You will learn to make decisions with if/else, organize code into functions, and manage collections of data with arrays and objects
  • You will learn the Document Object Model: selecting elements, changing their text and style, and creating new ones
  • You will learn events — clicks, typing, and form submission — so pages respond to users
  • You will learn modern JavaScript including arrow functions, template literals, and destructuring
  • You will learn to fetch JSON data from web addresses with the Fetch API
  • Finally, you will combine everything in a capstone to-do app with persistent storage

Prerequisites

You need a computer with a modern web browser — Chrome, Edge, Firefox, or Safari all work — and basic comfort using files and folders, such as creating and saving a file. No programming experience is required, and nothing needs to be installed: your browser already runs JavaScript. A tiny amount of HTML is used from Lesson 4 onward (tags like button and input), and each tag is explained where it first appears, so no prior HTML knowledge is needed either. You will need a plain text editor for writing code; the free VS Code is a popular choice, and the built-in Notepad on Windows or TextEdit on macOS (in plain text mode) works for this course. If you can follow written instructions and are willing to experiment, you are ready.
