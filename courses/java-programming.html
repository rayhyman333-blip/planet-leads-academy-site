What You Will Learn

  • You will learn how to set up Java on your computer, write a first program, and compile and run it from the command line
  • You will learn variables and the main types: whole numbers, decimal numbers, text, single characters, and true-or-false values
  • You will learn to make decisions with if, else if, and else, and to choose between options with switch
  • You will learn to repeat work with for loops and while loops
  • You will learn to organize code into methods with parameters and return values so you can reuse logic instead of copying it
  • You will learn arrays for storing and processing many values of the same type
  • You will learn classes and objects: how to define a class with fields and methods, create objects from it, and use constructors
  • Finally, you will apply all of it in a guided final project: a small catalog program with adding, listing, and searching

Prerequisites

You need a computer you are allowed to install software on, and basic comfort using files and folders, such as creating a folder and saving a file. No programming experience is required, and no math beyond everyday arithmetic is used. You will need an internet connection once, to download Java, and a plain text editor for writing code; any plain text editor works, and no specific editor or tool is required for this course. Everything else, concepts, vocabulary, and habits, is taught from zero inside the lessons. If you can follow written instructions and are willing to experiment, you are ready.

Estimated study time: 10 hours, at your own pace, no deadline. This is an estimate for reading the 8 lessons and doing the practice exercises — not a verified average completion time, and not a course length guarantee.
