What You Will Learn

  • You will learn what data analytics is and the four types of data (numbers, categories, text, and dates) plus how each one behaves
  • You will learn to use a spreadsheet to sort, filter, and run formulas on a dataset of hundreds of rows
  • You will learn a repeatable process for cleaning messy data: handling missing values, fixing inconsistent formats, removing duplicates, and checking your work
  • You will learn descriptive statistics in plain English — mean, median, mode, range, and standard deviation — and when each one is the right summary
  • You will learn visualization principles: which chart type fits which question, how to avoid misleading charts, and how to label honestly
  • You will learn SQL basics: selecting columns, filtering rows, sorting, grouping, and calculating averages and counts across a database table
  • You will learn to design a simple dashboard with key metrics, trend charts, and comparison views
  • Finally, you will walk through a complete case study from question to recommendation and get a roadmap for what to learn next

Prerequisites

You need a computer with any spreadsheet program installed — the free options built into most systems or available at no cost online all work, since the course uses standard features (sorting, filtering, common formulas, charts) that every spreadsheet program has. You need basic comfort with files and folders, such as creating a folder and saving a file. No programming experience is required, and the math never goes beyond arithmetic plus a few new averages explained from zero. Everything else — vocabulary, techniques, and habits — is taught inside the lessons. If you can follow written instructions and are willing to experiment with a spreadsheet, you are ready.

Estimated study time: 6 hours, at your own pace, no deadline. This is an estimate for reading the 8 lessons and doing the practice exercises — not a verified average completion time, and not a course length guarantee.
