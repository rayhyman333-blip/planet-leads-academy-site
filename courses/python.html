What You Will Learn

  • You will learn how to install Python, run code two different ways (the interactive prompt and script files), and read error messages without panic
  • You will learn variables, strings, numbers, and booleans, plus how to take input from a user and combine values with operators
  • You will learn to control what your program does with if/elif/else decisions and for and while loops
  • You will learn to organize code into reusable functions with parameters and return values
  • You will learn the four core collection types — lists, dictionaries, tuples, and sets — and when to reach for each one
  • You will learn to read and write files and to handle errors with try/except so your programs fail gracefully instead of crashing
  • Finally, you will apply all of it in two guided projects: a file-organizer automation script and a command-line expense tracker with saved data

Prerequisites

You need a computer you are allowed to install software on — Windows, macOS, or Linux all work — and basic comfort using files and folders, such as creating a folder and saving a file. No programming experience is required, and no math beyond everyday arithmetic is used. You will need an internet connection once, to download Python, and a plain text editor for writing code; the course shows you free options built into your system or available at no cost. Everything else — concepts, vocabulary, and habits — is taught from zero inside the lessons. If you can follow written instructions and are willing to experiment, you are ready.

Estimated study time: 10 hours, at your own pace, no deadline. This is an estimate for reading the 8 lessons and doing the practice exercises — not a verified average completion time, and not a course length guarantee.
