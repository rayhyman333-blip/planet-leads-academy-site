What You Will Learn

  • You will learn what data science is and how a data project moves from a question to an answer
  • You will learn to read and work with data tables: rows, columns, and the four types of data
  • You will learn a repeatable process for cleaning messy data: handling missing values, fixing inconsistent formats, removing duplicates, and checking your work
  • You will learn to describe data with summaries: averages, medians, ranges, and counts, and when each one is the right choice
  • You will learn to build honest charts and to spot charts that mislead
  • You will learn the idea behind prediction: using patterns in past data to make a careful forecast, and how to test whether a prediction is any good
  • You will learn to present findings clearly, with a short written summary and a few good charts
  • Finally, you will carry out a complete small project from start to finish

Prerequisites

You need a computer with any spreadsheet program installed: the free options built into most systems or available at no cost online all work, since the course uses standard features such as sorting, filtering, common formulas, and charts that every spreadsheet program has. You need basic comfort with files and folders, such as creating a folder and saving a file. No programming experience is required, and the math never goes beyond arithmetic plus a few new averages explained from zero. The course is tool-agnostic: it describes concepts and plain steps that work in any spreadsheet program or on paper, and it does not require any one specific paid product. Everything else, vocabulary, techniques, and habits, is taught inside the lessons. If you can follow written instructions and are willing to experiment with a spreadsheet, you are ready.
