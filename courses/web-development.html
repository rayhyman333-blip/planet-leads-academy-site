What You Will Learn

  • You will learn how the web works — browsers, servers, and addresses — and how to create your first HTML page and view it locally
  • You will learn HTML structure: headings, paragraphs, links, images, lists, forms, and semantic page sections
  • You will learn CSS basics: selectors, colors, typography, and the box model of padding, borders, and margins
  • You will learn modern layout with flexbox and responsive design with media queries so your pages look right on phones and desktops
  • You will learn JavaScript fundamentals: variables, data types, functions, conditionals, loops, and events
  • You will learn to manipulate the page with the DOM: finding elements, changing text and styles, and responding to clicks
  • You will learn to build and validate forms and complete a small interactive project
  • Finally, you will publish your site to free hosting and plan a capstone project

Prerequisites

You need a computer you are allowed to install software on — any modern system works — and basic comfort using files and folders, such as creating a folder and saving a file. No programming experience is required, and no math beyond everyday arithmetic is used. You will need a web browser (any current one works) and a plain text editor for writing code; the course points you to free options. An internet connection is needed once to reach free hosting in the final lesson. Everything else — concepts, vocabulary, and habits — is taught from zero inside the lessons. If you can follow written instructions and are willing to experiment, you are ready.

Estimated study time: 10 hours, at your own pace, no deadline. This is an estimate for reading the 8 lessons and doing the practice exercises — not a verified average completion time, and not a course length guarantee.

Lifetime access: One payment — no subscription, no expiry date, no deadline. You keep access to this course through the Academy’s student system for as long as Planet Leads Academy operates.
