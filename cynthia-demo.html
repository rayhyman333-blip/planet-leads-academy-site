Cynthia MCP Server — Live Demo

MCP ServerVerified answers only

Cynthia, by Planet Leads — created by Ramel Hyman. Cynthia is a plain-English AI assistant that answers only from her verified knowledge. She runs as a public MCP (Model Context Protocol) server: any MCP client can connect to her and call her three tools. This page demonstrates all three tools with real responses captured live from the public endpoint — nothing on this page was typed by hand or made up.

Live endpoint: https://cynthia-mcp-server.onrender.com/mcp
Source code: github.com/rayhyman333-blip/cynthia-mcp-server
Server: cynthia 1.0.0 · Protocol: MCP 2024-11-05

How this demo works. Every transcript below is a real request and a real response captured live from the public endpoint on 17 November 2026, using the MCP protocol (initialize, then tools/list, then tools/call). The endpoint does not send a cross-origin (CORS) header, so a web page cannot call it directly from your browser — that is why this page shows captured transcripts instead of a live try-it box. The endpoint itself is public, free, and needs no key: connect it in any MCP client and the same calls return the same answers.

The three tools

  • ask_cynthia — Ask Cynthia a question. She answers ONLY from her verified
  • cynthia_capabilities — Describe what Cynthia can do and the rules she follows
  • cynthia_status — Report the Cynthia MCP server version, the number of verified

ask_cynthia

Ask Cynthia a question. She answers ONLY from her verified
knowledge, returning the verified answer verbatim labelled
"Verified answer". If the question is not in her verified knowledge,
she honestly abstains instead of guessing.

Args:
question: The question to ask Cynthia, in plain English.

cynthia_capabilities

Describe what Cynthia can do and the rules she follows
(verified answers only, owner approval on risky actions,
free-only building, subscription guard, and more).

cynthia_status

Report the Cynthia MCP server version, the number of verified
facts in her knowledge store, and a health check.

Why verified answers

Cynthia's knowledge is a store of 33 owner-approved verified facts. Every answer comes verbatim from one of those facts — never from a model guessing. On held-out test questions she scored 0 inventions: she either gives the verified answer or honestly abstains. A new fact is added only when the owner approves it.

Server instructions (from the live initialize response):

Cynthia, by Planet Leads — created by Ramel Hyman. Ask her questions with ask_cynthia; she answers only from her verified facts and honestly abstains when she does not know. Use cynthia_capabilities to learn what she can do, and cynthia_status to check the server.

Connect to Cynthia

Add the public endpoint to any MCP client as a remote (Streamable HTTP) server:

{
  "mcpServers": {
    "cynthia": {
      "url": "https://cynthia-mcp-server.onrender.com/mcp"
    }
  }
}

No API key, no account, no payment. Free to call.
